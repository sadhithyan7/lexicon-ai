# LEXICON AI — DESIGN SYSTEM

## Design Philosophy

Quiet, precise, editorial, professional.

The interface should feel like a serious software product,
not an AI-generated landing page.

The design should communicate through hierarchy, typography,
spacing, structure and information.

Avoid decoration unless it has a functional purpose.

# COLOR RULE

Use neutral colors for the majority of the interface.

Use the accent color selectively.

Color should communicate:

- interaction
- selection
- status
- emphasis

Do not use color simply to make the interface more visually exciting.

NO:

- purple-blue gradients
- neon colors
- glow
- gradient text
- decorative color blobs

# BORDER RADIUS

Use restrained radius.

Small:
4px

Medium:
6px

Large:
8px

Avoid excessive rounded interfaces.

---

# BORDERS

Prefer subtle borders over shadows.

Default:

1px solid #DEDEDB

Use shadows only when elevation is functionally necessary.

---

# ICONS

Use Lucide icons.

Preferred sizes:

16px
18px
20px
24px

Icons must communicate function.

Never use emojis as UI icons.

---

# BUTTONS

6px

# CARDS

Cards are not the default container.

Use a card only when information needs explicit grouping.

Default:

background: #FFFFFF
border: 1px solid #DEDEDB
radius: 8px

Avoid excessive shadows.

---

# LAYOUT

Desktop maximum width:

1200px

Use a 12-column grid where appropriate.

Maintain strong horizontal alignment.

---

# VISUAL DENSITY

This is a product interface.

Prefer meaningful information density over large empty
marketing sections.

Do not use huge hero sections unless the page is specifically
a marketing landing page.
