# PAGE DESIGN RULES

Before implementing any page, determine:

## 1. PURPOSE

What is the page actually for?

## 2. PRIMARY USER

Who is using this page?

## 3. PRIMARY ACTION

What is the most important thing the user should do?

## 4. INFORMATION HIERARCHY

Classify information as:

Primary
Secondary
Supporting
Metadata

## 5. LAYOUT

Determine:

- header
- navigation
- content
- sidebar
- sections
- footer

## 6. DENSITY

Determine whether the page requires:

Low density
Medium density
High density

Do not automatically create a spacious marketing layout.

## 7. RESPONSIVENESS

Define how the hierarchy changes on:

- desktop
- tablet
- mobile

## 8. COMPONENTS

Reuse existing components where possible.

Only create new components when necessary.

## 9. VISUAL AUDIT

After implementation check:

- alignment
- spacing
- hierarchy
- typography
- color
- consistency
- responsive behavior
